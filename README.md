# Dr Haitham GCC landing page

Updated Arabic RTL static landing page using the three supplied WebP assets. Target keywords are used in page title, description, headings, and content without keyword stuffing.

## Files
- `index.html` main page and SEO metadata
- `styles.css` responsive styles
- `assets/banner.webp`, `assets/whatsapp-contact.webp`, `assets/site-logo.webp`
- `robots.txt`, `sitemap.xml`, `privacy.html`

## Publish
Upload all files and the `assets` folder to the root of `femseha/dr-haitham-gcc-landing`, commit to `main`, and keep GitHub Pages configured to `main` / `/(root)`.

Product registration, legal classification, and advertising permissions must be verified separately in every target country. The supplied artwork contains claims/contact details that should not be treated as proof of a licensed clinical service or regulatory approval.
