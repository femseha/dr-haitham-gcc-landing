# صفحة هبوط عربية — دكتور هيثم

قالب HTML/CSS متجاوب للنشر عبر GitHub Pages. القالب تجاري عام لمنتج صحي قانوني ومصرح بتسويقه في السوق المستهدف، وليس إعلانًا جاهزًا لدواء محدد.

## الملفات
- `index.html`: الصفحة الرئيسية وبيانات SEO.
- `styles.css`: التصميم المتجاوب.
- `robots.txt`: توجيهات الزحف.
- `sitemap.xml`: خريطة الموقع.
- `privacy.html`: قالب سياسة الخصوصية.

## قبل النشر
1. استبدل `YOUR-USERNAME` و`YOUR-REPOSITORY` بروابط حسابك ومستودعك.
2. أضف بيانات المنتج الدقيقة المثبتة على الملصق والنشرة.
3. تحقق من تسجيل المنتج وتصنيف الإعلان ومتطلبات كل دولة خليجية مستهدفة.
4. لا تضف ادعاءات طبية أو اعتمادات أو ضمانات غير مثبتة.
5. خصص سياسة الخصوصية لتطابق الممارسات الفعلية.

## GitHub Pages
1. ارفع الملفات إلى جذر مستودع جديد.
2. افتح Settings > Pages.
3. اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
4. بعد النشر حدّث الروابط canonical وOpen Graph وsitemap بالرابط النهائي.
5. النشر لا يضمن الفهرسة أو ترتيبًا معينًا في Google.

القالب ثابت ولا يحتوي على قاعدة بيانات أو معالجة مدفوعات.
